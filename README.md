A comprehensive Lost and Found Management System developed in C# with Windows Forms and MySQL database. Designed for the University of Moratuwa to efficiently manage lost and found items across campus.

## Features:
- 🔐 Secure user authentication with password hashing (SHA256)
- 👥 Role-based access (Admin & User)
- 📦 Item registration and tracking
- 🔍 Search and filter functionality
- 📊 Admin dashboard for full management
- 👤 User dashboard for personal item management
- 🎨 Modern UI with custom design

## Tech Stack:
- **Frontend:** Windows Forms (.NET Framework)
- **Backend:** C#
- **Database:** MySQL
- **Security:** SHA256 password hashing
- **UI Library:** MaterialSkin

## Setup Instructions:
1. Clone the repository
2. Update the connection string in `DatabaseHelper.cs`
3. Run the SQL script to create the database schema
4. Build and run the application
